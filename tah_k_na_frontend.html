CSS Flexbox (Centrování)

Absolutní základ! Jak vycentrovat prvek dokonale na střed (horizontálně i vertikálně)? Musíš to aplikovat na rodičovský kontejner.

.kontejner {
  display: flex;
  justify-content: center; /* Horizontální střed */
  align-items: center;     /* Vertikální střed */
  height: 100vh;           /* Musí mít výšku! */
}

Chyták: Pokud změníš směr přes flex-direction: column;, osy se prohodí! justify-content pak centruje vertikálně.

CSS Pozicování

Jakmile použiješ position: absolute; nebo fixed, prvek se vytrhne z normálního toku dokumentu. Ostatní prvky se chovají, jako by tam vůbec nebyl.

  • static - výchozí, normální tok dokumentu.
  • relative - zůstává v toku, ale můžeš s ním hýbat (top, left). Tvoří záchytný bod pro absolutní potomky!
  • absolute - vytržen z toku. Pozicuje se vůči nejbližšímu předkovi, který má relative/absolute/fixed.
  • fixed - vytržen z toku. Fixován k oknu prohlížeče (zůstává při scrollu).
Blokové vs Inline prvky
Blokové prvky (div, p, h1, section) Zabírají 100% dostupné šířky. Začínají na novém řádku. Můžeš jim nastavovat width, height, margin i padding.
Inline prvky (span, a, strong) Zabírají jen šířku svého obsahu. Řadí se vedle sebe. Nemůžeš jim nastavit výšku/šířku! Margin-top a bottom na ně často nefunguje správně.

Řešení (Chyták): Použij display: inline-block;. Prvek zůstane v řádku, ale můžeš mu dát padding i rozměry (ideální pro tlačítka).

JS: Výběr z DOMu

Nejuniverzálnější metoda je dnes querySelector. Používá stejné selektory jako CSS!

// Výběr podle třídy (nezapomeň na TEČKU!)
const modal = document.querySelector(".modal-box");

// Výběr podle ID (nezapomeň na KŘÍŽEK!)
const btn = document.querySelector("#hlavni-tlacitko");

// Zastaralá metoda (zde se naopak # nepíše):
const btn2 = document.getElementById("hlavni-tlacitko");
JS: Zachytávání událostí

Častá chyba: Psát do HTML <button onclick="funkce()"> je zastaralé a špatné. V JS se názvy událostí píšou BEZ slovíčka "on". 

const tlacitko = document.querySelector(".btn");

// Správně! Použij "click", nikoliv "onclick"
tlacitko.addEventListener("click", function() {
    console.log("Kliknuto!");
});
JS: Úprava CSS stylů

JavaScript nepodporuje v názvech proměnných pomlčky. Proto se všechny CSS vlastnosti přepisují z kebab-case do camelCase (velbloudí notace).

  • background-color ➡️ backgroundColor
  • font-size ➡️ fontSize
const box = document.querySelector(".box");

// 1. Změna inline stylu
box.style.backgroundColor = "red";

// 2. Lepší cesta? Přidat CSS třídu
box.classList.add("aktivni");
